# 営業の相棒 PWA試験画面

GitHub Pagesの固定URLから、会社所有の独立した試験GASへ架空データを読み書きする試験画面です。正式なGoogleログインはまだありません。試験データは誰でも閲覧・追加できるため、実在の名前や案件、個人情報、業務データを入力しないでください。

既存のマニフェストの `id`、`scope`、`start_url` は維持しています。`standalone` で表示し、対応ブラウザでは `focus-existing` により起動済み画面への復帰を指定します。実際の動作は各端末で確認してください。

サービスワーカーは画面表示に必要な静的ファイルだけを保存し、APIの応答は保存しません。ファイル更新時はキャッシュ名を変更し、既存利用者への更新方法を確認してください。保存結果が不明な要求は、要求IDと架空の入力内容を端末に保存して再送できるようにします。

## 試験

PCのChrome・Edge、Android、iPhoneでインストールとアイコンを確認します。PCでは、開いたままアイコンを再度押した際の表示も確認します。iPhoneはSafariとホーム画面に追加した状態の両方を確認します。
