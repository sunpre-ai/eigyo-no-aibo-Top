# 見積受付の担当決め

新規見積の受付を水金さんへ知らせ、CAD画面のホームに「見積のCAD担当を決定」を表示する。お知らせ、または一覧から案件を開き、CADの名前を選んで「CAD担当を決定して依頼する」を押すと、管理台帳に担当を保存し、その本人へ見積依頼を通知する。

水金さんの新操作は初回見積のCAD決定だけ。営業・金額・原価・版・実績の入力は増やさない。既に担当決定した後の変更は管理者の従来操作を使用する。営業の新規登録画面は「担当CADは水金さんが決定」と案内し、CADの選択を省く。シート直接受付も同じGAS処理を使う。

対応するGAS変更を先に公開し、その成功確認後に本PRをPagesへ公開する。新API saveQuoteCadAssignment、home/detail の quoteCadAssignmentRequests、quoteAssignmentPeople、quotes の quoteCadAssignmentByLeader を使う。軽量ホームの案件取得範囲を広げず、担当決め一覧は最新の見積から金額なしで取得する。担当未設定の案件でもお知らせから詳細を取得できる。

URL、認証、閲覧範囲、保存先、トリガー、manifestは維持する。サービスワーカーの版を更新する。更新は入力途中の画面を残して別タブで確認する。復旧は両PRを取り消すPRを作成して既存公開手順で反映し、保存済み担当・履歴・通知は削除しない。
