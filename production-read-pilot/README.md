# 営業の相棒の案件照合画面

`node production-read-pilot/serve.mjs --fixture` で架空データを表示する。PC内の `http://127.0.0.1:8787/` を開き、`00000000-0000-4000-8000-000000000001` を入力すると、営業・CAD・管理者の絞り込みを確認できる。

本番照合の承認後は、引数を承認済みの本番GASの `/exec/api/v1` のHTTPS URLに変更する。起動先はPC内のループバック。案件・照合コード・セッションはブラウザーのメモリ内で扱い、外部配信、ファイル出力、ログを行わない。既存の試験画面を配信するGitHub Pagesへは公開しない。

照合は案件一覧の件数・担当範囲・表示中の項目を対象とする。本番APIが有効で、現行GAS版から照合コードを得られた場合だけ接続できる。
